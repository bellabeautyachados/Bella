# Achadinhos IA — versão 2

Esta versão funciona como site e aplicativo instalável (PWA).

## Como testar no computador
Abra `index.html`.

## Como publicar
Envie todos os arquivos para uma hospedagem de site estático.

## Como trocar os produtos
Abra `products.js` e altere:
- name
- category
- store
- description
- oldPrice
- price
- emoji
- link

Cole o seu link de afiliada no campo `link`.

## Como trocar o WhatsApp
Abra `app.js` e procure:
`const whatsappNumber = "5511999999999";`

Troque pelo número desejado, com 55 + DDD + número, sem espaços.

## Importante
Os produtos, preços e links presentes são exemplos.
